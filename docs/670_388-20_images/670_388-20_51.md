## 2.2 Program Defaults for Cycles

### Entering GLOBAL DEF definitions

| Control / Key | Action Description |
| :--- | :--- |
| ![Programming and Editing Mode Key](icon_pgm_edit.png) | Select the Programming and Editing operating mode. |
| **SPEC FCT** | Press the Special Functions key. |
| **PROGRAM DEFAULTS** | Select the functions for program defaults. |
| **GLOBAL DEF** | Select **GLOBAL DEF** functions. |
| **100 GLOBAL DEF GENERAL** | Select the desired GLOBAL DEF function, e.g. **GLOBAL DEF COMMON** |
| | Enter the required definitions, and confirm each entry with the **ENT** key. |

### Using GLOBAL DEF information

If you have entered the corresponding GLOBAL DEF functions at the beginning of the program, then you can link to these globally valid values when defining any canned cycle.

Proceed as follows:

| Control / Key | Action Description |
| :--- | :--- |
| ![Programming and Editing Mode Key](icon_pgm_edit.png) | Select the Programming and Editing operating mode. |
| **CYCL DEF** | Select the canned cycles. |
| **DRILLING/THREAD** | Select the desired group of cycles, for example: drilling cycles. |
| **200** | Select the desired cycle, e.g. **DRILLING**. |
| | The TNC displays the SET STANDARD VALUES soft key, if there is a global parameter for it. |
| **SET STANDARD VALUES** | Press the SET STANDARD VALUES soft key. The TNC enters the word **PREDEF** (predefined) in the cycle definition. You have now created a link to the corresponding **GLOBAL DEF** parameter that you defined at the beginning of the program. |

---

> ### ⚠️ Danger of collision!
>
> Please note that later changes to the program settings affect the entire machining program, and can therefore change the machining procedure significantly.
>
> If you enter a fixed value in a canned cycle, then this value will not be changed by the **GLOBAL DEF** functions.
