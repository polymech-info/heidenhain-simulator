## 2.2 Program Defaults for Cycles

### Overview

All Cycles 20 to 25, as well as all of those with numbers 200 or higher, always use identical cycle parameters, such as the setup clearance **Q200**, which you must enter for each cycle definition. The **GLOBAL DEF** function gives you the possibility of defining these cycle parameters once at the beginning of the program, so that they are effective globally for all canned cycles used in the program. In the respective canned cycle you then simply link to the value defined at the beginning of the program.

The following GLOBAL DEF functions are available:

| :--- | :---: | :--- |
| **GLOBAL DEF COMMON**<br>Definition of generally valid cycle parameters | ![GLOBAL DEF GENERAL] | Page 52 |
| **GLOBAL DEF DRILLING**<br>Definition of specific drilling cycle parameters | ![GLOBAL DEF DRILLING] | Page 52 |
| **GLOBAL DEF POCKET MILLING**<br>Definition of specific pocket-milling cycle parameters | ![GLOBAL DEF POCKET MILLING] | Page 53 |
| **GLOBAL DEF CONTOUR MILLING**<br>Definition of specific contour milling parameters | ![GLOBAL DEF CNTR MILLING] | Page 53 |
| **GLOBAL DEF POSITIONING**<br>Definition of the positioning behavior for **CYCL CALL PAT** | ![GLOBAL DEF POSITIONING] | Page 53 |
| **GLOBAL DEF PROBING**<br>Definition of specific touch probe cycle parameters | ![GLOBAL DEF PROBING] | Page 54 |
